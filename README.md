# Student Performance Data Analysis

## Project Overview
This project analyzes student performance using Python. It explores different factors that may be related to students' exam scores.

## Objectives
- Explore student performance data.
- Check and handle missing values.
- Remove duplicate records.
- Perform basic statistical analysis.
- Create graphs to understand the data.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Google Colab

## Data Analysis
The project includes:
- Dataset overview
- Missing value checking
- Data cleaning
- Statistical analysis
- Data visualization
- Key findings and conclusion

## Visualizations
- Exam Score Distribution
- Study Hours vs Exam Score
- Parental Involvement vs Exam Score

## Conclusion
This project helps understand student performance data through Python and data visualization. It provides insights into study hours, attendance, exam scores and other factors.
